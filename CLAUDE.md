# traficar-map

React 19 + TypeScript + Vite + Tailwind v4 + shadcn/ui + Leaflet (react-leaflet).

## Skills to use

- `tailwind-v4-shadcn` — use for Tailwind v4 setup, `@theme inline`, CSS variables, dark mode/ThemeProvider, shadcn component work.
- `vite-patterns` — use for vite.config.ts changes, plugins, env vars, build/HMR issues.
- `vercel:react-best-practices` — use after editing TSX components (hooks, structure, a11y, perf).
- `frontend-design` — use when making visual/UI design decisions.
